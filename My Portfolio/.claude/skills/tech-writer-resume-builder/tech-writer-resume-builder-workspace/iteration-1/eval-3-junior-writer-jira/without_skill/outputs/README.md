## Converting Formats

### Markdown to PDF
```bash

# Visit md2pdf.netlify.app or dillinger.io
```

```bash

```

### HTML to PDF
1. Open resume.html in Chrome/Firefox
2. Press Ctrl+P (or Cmd+P on Mac)
3. Select "Save as PDF"
4. Click Save
