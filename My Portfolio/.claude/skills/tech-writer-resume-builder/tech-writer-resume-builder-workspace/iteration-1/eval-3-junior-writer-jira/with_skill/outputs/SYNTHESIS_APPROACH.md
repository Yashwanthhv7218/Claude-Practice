## ATS Optimization Decisions

### 1. Single-Column Layout
- No tables, graphics, or fancy formatting
- Linear flow of information
- Compatible with all ATS systems
- All content machine-readable

### 2. Keyword Emphasis for Technical Writers
- **Prioritized:** API Documentation, JIRA, Confluence, Markdown, Git, user guides
- **Structured format:** Competencies section lists 15+ keywords
- **Achievement focus:** Metrics (scores, percentages, counts) scannable
- **Semantic HTML** (in resume.html): Proper heading hierarchy for text parsing

### 3. Metrics-First Approach
- Every bullet starts with quantifiable achievement
- Numbers are conspicuous (45 tasks, 4.3/5, 85%, 20%, 3-day, 12 guides)
- Demonstrates impact (reduction, improvement, completion, feedback)
- ATS systems weight quantified claims higher than subjective descriptions

### 4. Performance Ratings Section
- Dedicated section for competency scores
- Separate from experience to ensure visibility
- Rating badges (4.2/5, 4.0/5, etc.) stand out visually and in text parsing
- Validator of claims made elsewhere in resume

### 5. Clear Skill Categories
- "Core Competencies" section groups related skills
- Each category labeled (Technical Writing, Tools, Capabilities, Languages)
- Prevents category confusion in keyword search
- Improves readability for human review

## HTML Resume Specific Features

### Visual Hierarchy
- **Header:** Large name (2.5em), title with accent color (#e74c3c red), contact links
- **Sections:** Bold h2 headers with left red border, uppercase, letter-spacing
- **Achievements:** Highlight box with light background, grid layout for scannability

### Color Scheme
- **Primary:** #2c3e50 (dark blue-gray) for text and structure
- **Accent:** #e74c3c (coral red) for emphasis, bullets, borders
- **Supporting:** #555 (medium gray) for body text, #888 (light gray) for metadata
- **Background:** #f9f9f9 (off-white) for page, #f0f8f7 (light teal) for highlights

### Responsive Design
- **Desktop (>768px):** Two-column highlight grid, side-by-side layouts
- **Tablet (480-768px):** Single-column highlights, optimized spacing
- **Mobile (<480px):** Simplified typography, single column, reduced padding
- **Print:** Optimized margins, page-break rules, removed shadows

### Accessibility
- Semantic HTML (header, section, footer)
- Proper heading hierarchy (h1 → h2 → h3)
- Link styling with hover states
- High contrast ratios (WCAG AA compliant)
- Alt text considerations (icons are Unicode, screen-reader friendly)
