## ⚡ Quick Start

### **Step 1: Edit Your Resume**
Open `resume.md` and make changes:
- Add achievements
- Update metrics
- Change dates
- Modify skills

### **Step 2: Auto-Sync to HTML**

**Windows:**
```bash
sync_resume.bat
```

**Mac/Linux:**
```bash
./sync_resume.sh
```

Or directly:
```bash
python sync_resume.py
```

### **Step 3: Done!**
Both `resume.md` and `resume.html` are now in sync.

## 🔄 How Auto-Sync Works

```
1. You edit resume.md
   ↓
2. You run sync script
   ↓
3. Script reads resume.md
   ↓
4. Script extracts all sections
   ↓
5. Script fills HTML template
   ↓
```
